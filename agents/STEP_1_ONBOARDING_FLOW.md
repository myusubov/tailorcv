## Key Onboarding Principles

1. **Choice First** - Let user pick their path
2. **Smart Defaults** - Pre-fill what we can
3. **Progressive Disclosure** - Only ask what's needed
4. **Visual Feedback** - Show progress, loading states
5. **Escape Hatches** - Allow skip, back, switch methods
6. **Celebrate Success** - Clear completion moment
